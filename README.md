# Дипломный проект по автоматизации тестирования на JavaScript

**Автор:** Екатерина Шутько

Этот проект был разработан в рамках дипломной работы на курсе Skillbox по специальности «Инженер по ручному тестированию» с углублённым изучением JavaScript. Его цель — продемонстрировать навыки написания автотестов для проверки веб-приложений.

---

## 🎯 О проекте

В рамках дипломной работы я разработала набор автоматизированных тестов, которые проверяют функциональность типового веб-приложения (интернет-магазин, API или сервис). Проект показывает моё понимание:
- Структуры и логики автотестов
- Использования популярных библиотек и фреймворков
- Оформления кода и отчётов о тестировании

---

## 🛠️ Используемые инструменты

| Инструмент | Назначение |
|------------|------------|
| **JavaScript** | Язык написания тестов |
| **Mocha** | Фреймворк для написания тестов (описание `describe/it`) |
| **Chai** | Библиотека для утверждений (проверка результатов) |
| **Node.js** | Среда выполнения тестов |
| **NPM** | Менеджер пакетов |
